PortraitCam - Samsung-style portrait camera (CameraX + ML Kit)

APK বানানোর সহজ উপায় (Android Studio ছাড়া):
1) github.com এ একটা নতুন repository খুলুন (Private হলেও চলবে)।
2) এই zip এর ভেতরের সব ফাইল/ফোল্ডার (.github সহ) repository তে upload করুন।
3) Actions ট্যাব -> "Build APK" -> Run workflow (বা upload করলেই নিজে চলবে)।
4) ৫-৮ মিনিট পর run এ ক্লিক করে নিচে Artifacts থেকে PortraitCam-apk নামান।
5) zip খুলে app-debug.apk ফোনে দিন, install করুন ("Unknown sources" allow করতে হবে)।

Android Studio থাকলে: ফোল্ডারটা Open করে Build > Build APK(s)।
